# claude-skills

Collection of [Claude Code](https://claude.ai/code) skills for common workflows.

## Skills

| Skill | Description |
|-------|-------------|
| [arxiv-search](./arxiv-search/) | Search arXiv for papers by keywords and date range |
| [arxiv-to-tracking](./arxiv-to-tracking/) | Convert arxiv-search JSON to monthly tracking and category markdown docs |

## Installing a skill

Copy the skill directory into your local skills folder:

```bash
cp -r path/to/<skill> ~/.claude/skills/<skill>
```

Restart Claude Code and it'll be ready to use.
